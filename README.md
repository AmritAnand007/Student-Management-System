# Student Management System in C

This is a simple Student Management System made using C.

I created this project to practice C programming and learn how file handling works. The program allows us to add, view, search, and delete student records.

## Features

* Add student
* Display all students
* Search student by ID
* Delete student
* Save student records in a file
* Simple menu-based program

## Technologies Used

* C
* Structures
* Functions
* File Handling
* Loops
* Conditional Statements

## Project Structure

```text
Student-Record-Management-System-C/
│
├── main.c
├── students.txt
└── README.md
```

### main.c

This file contains the main C program and all the functions used in the project.

### students.txt

This file is used to store the student records.

It is empty when the project is started. The records are added automatically when we use the program.

### README.md

This file contains information about the project and how to run it.

## How to Run

First, open the terminal in the project folder.

Compile the program:

```bash
gcc main.c -o student
```

Run the program:

```bash
.\student
```

## Menu

```text
1. Add Student
2. Display Students
3. Search Student
4. Delete Student
5. Exit
```
